title: "From Field to Code: PyQGIS from Scratch"
---

Build a real tool and learn to think like an engineer.

This book follows a single real problem from start to finish: which homes stand close to overhead power lines, and how long help takes to reach them, by day and by night. Along the way you'll learn Python and PyQGIS, but above all you'll see how an engineer thinks: how to frame the problem, find the right tool, check every step and know when a result can be trusted.
