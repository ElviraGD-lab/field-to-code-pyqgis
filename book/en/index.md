**Build a real tool and learn to think like an engineer**

This book is for people who know QGIS well but have never written a line of code.

We go from one real problem all the way to a working tool. The problem is this: which homes stand close to overhead power lines, and how long does it take help to reach them, by day and by night?

Along the way, we learn Python and PyQGIS from scratch, right inside QGIS, and only what the task needs. But the main thing is that we learn to think like an engineer:

- how to define the task;
- how to find the right tool;
- how to check every step;
- when we can trust a result.

By the end, we'll have a QGIS plugin that works out the answer for any municipality.
