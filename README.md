# From Field to Code: PyQGIS from Scratch

Build a real QGIS tool, from an empty folder to a working Processing algorithm, and learn to think like an engineer on the way.

Book 1 of the *From Field to Code* series. Written in Spanish and English.

> Status: work in progress (started November 2026). Published so far: the prologue and lessons 1.1, 1.2, 2.1 and 2.2.

- Read the book: https://elviragd-lab.github.io/field-to-code-pyqgis/
- The whole series: https://elviragd-lab.github.io

## What you build

A QGIS 4 Processing algorithm that answers one question for any municipality: which residential buildings stand close to overhead power lines, and how long fire crews take to reach them, by day and by night. At the end the algorithm is packaged as a QGIS plugin. The worked example is Lena, in Asturias (Spain).
